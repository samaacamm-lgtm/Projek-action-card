# 🃏 Duel Kartu Strategi

**Duel Kartu Strategi** adalah game kartu berbasis web (*turn-based strategy card game*) yang dapat dimainkan langsung melalui browser. Kalahkan lawanmu dengan menyusun strategi menggunakan kombinasi kartu serangan, pertahanan, serta efek taktis lainnya!

🌐 **Mainkan Sekarang:** [drivedio.my.id](https://drivedio.my.id)

---

## ✨ Fitur Utama

* **🤖 Player vs AI:** Tantang bot dengan 4 tingkat kesulitan yang berbeda:
  * **Easy:** Bot sering memilih secara acak, terkadang melewatkan giliran, dan tidak memakai *stack*.
  * **Normal:** Bot bermain wajar namun terkadang meleset dan tidak memakai *stack Time*.
  * **Hard:** Bot memperhitungkan hasil tiap kemungkinan langkah, termasuk *stack Buff* dan *Time*.
  * **Extreme:** Mirip seperti *Hard*, ditambah kemampuan membaca kartu di tanganmu dan memperhitungkan serangan balasan.
* **⚔️ Player vs Player (PvP):** Bermain bersama teman di dua perangkat berbeda secara *real-time* cukup dengan membuat ruangan (*room*) dan membagikan **kode 8 digit**.
* **🛡️ Sistem Hero & Health Card:** Pilih Hero dengan status HP dan jumlah *Health Card* tertentu (seperti *The Colossal Tank* dan *The Saboteur*).
* **🃏 Mekanik Kartu & Stack:** Kelola kartu **Attack**, **Defense**, **Debuff**, **Buff**, dan **Time** dengan sistem *Shared Draw* serta log pertarungan langsung.
* **📖 Panduan Lengkap:** Dilengkapi menu **Cara Bermain** dan **Panduan Kartu** langsung di dalam game untuk memudahkan pemain baru.

---

## 🛠️ Teknologi yang Digunakan

* **HTML5** – Struktur halaman dan antarmuka permainan.
* **CSS3** – Desain responsif dengan tema gelap (*dark mode*) yang nyaman di mata.
* **JavaScript (Vanilla JS)** – Logika permainan, sistem AI, dan manajemen *room* PvP.

## 🚀 Cara Menjalankan Secara Lokal

Jika kamu ingin menjalankan atau mengembangkan proyek ini di komputer lokal:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com
   ```
2. **Masuk ke direktori proyek:**
   ```bash
   cd Projek-action-card
   ```
3. **Jalankan game:**
   Buka file `index.html` langsung di browser pilihanmu, atau gunakan ekstensi seperti **Live Server** di VS Code.
